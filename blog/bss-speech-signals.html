Stereo BSS via Unfolded Complex Givens Rotations — what I built and why it's harder than ICA

For my MSc research at TU Ilmenau, I built a stereo Blind Source Separation system that goes significantly beyond classical ICA. The goal: given a two-microphone recording of two simultaneous speakers, recover each speaker separately — without knowing anything about the room, the microphone positions, or the speakers themselves.

This post covers the actual approach I took (unfolded complex Givens rotations), the problem that nearly derailed the whole thing (output collapse), and what the numbers actually mean.

Why not just use ICA?

Independent Component Analysis is the textbook answer to BSS. It works by assuming source signals are statistically independent and finding a demixing matrix that maximises that independence. Simple, elegant, and works well for synthetic signals.

The problem with real speech: consecutive audio frames are temporally correlated, which violates ICA's independence assumption. You also lose all spatial information — ICA doesn't care that the mixture came from two microphones at specific positions in a real room with real reverberation. And it's not learnable: ICA has no trainable parameters, so you can't improve it with data.

The approach I implemented instead: deep unfolding of complex-valued Givens rotations, with a discriminative loss to prevent collapse.

Givens rotations in the STFT domain

The core idea is to work in the Short-Time Fourier Transform domain, where the stereo mixture becomes a complex-valued spectrogram X ∈ ℂ^(2×F×T). At each frequency bin f, we apply a rotation: 

y₁(f,t) = cos(θ_f) · x₁(f,t) + exp(jφ_f) · sin(θ_f) · x₂(f,t)
y₂(f,t) = -exp(-jφ_f) · sin(θ_f) · x₁(f,t) + cos(θ_f) · x₂(f,t)

The angle θ_f controls how much each microphone contributes at that frequency. The phase φ_f handles the inter-channel phase difference — which encodes spatial information about where the speaker is relative to the microphones. This is a unitary transformation, so it preserves signal energy.

The "deep unfolding" part: instead of solving this analytically (which doesn't work for reverberant conditions), we unroll K iterations of a gradient update into a feedforward network with learnable step sizes per iteration. The network learns when to update aggressively and when to be conservative at each frequency.

The collapse problem

The first version of training converged perfectly — and produced completely useless outputs. Both output channels were nearly identical, each a near-copy of the mixture. This is called output collapse, and it's surprisingly hard to avoid.

The model found a trivial solution: y₁ = y₂ ≈ mixture / 2. This minimises reconstruction loss, since both sources are present in the mixture — but it's useless for separation. The standard Permutation Invariant Training (PIT) loss doesn't prevent this.

The fix was a custom discriminative loss term: 

# Penalise positive correlation between output magnitudes
L_discrim = ReLU( sum(|y₁| * |y₂|) / power )

L_total = L_PIT + α * L_discrim  # α = 0.05 worked well

The weight α is critical. Too low and collapse happens anyway. Too high and the model learns to make outputs maximally different regardless of content quality — which produces clean separation of total garbage. Getting this right took most of the iteration time.

Data pipeline

I used LibriSpeech (800 utterances, 50+ speakers) mixed with room impulse responses generated via pyroomacoustics. Each training sample is a 4.5-second stereo mixture at a random SNR (-5 to +8 dB) in a simulated room with RT60 between 0.1 and 0.6 seconds — covering everything from a dry studio to a reverberant office.

Seven augmentation strategies were applied online during training: channel swap, time shift, per-channel phase rotation, magnitude scaling, frequency masking, time masking, and low-level additive noise. Without these, the model memorised the training rooms and generalised poorly.

Results

On the test set (held-out rooms and speakers):

  • SIR 7–9 dB — Source-to-Interference Ratio (the main metric: how much of the other speaker leaks through)
  • SDR 5–7 dB — Source-to-Distortion Ratio (overall quality)
  • SAR 12–15 dB — Source-to-Artifacts Ratio (low artificial noise introduced)
  • ~0.15s per 4.5-second mixture on GPU

These are reasonable for a two-channel system on reverberant data without oracle masks or speaker enrollment. The SAR being relatively high means the separation is clean when it works — the main failure mode is interference leakage in highly reverberant conditions (RT60 > 0.5s), not artifact generation.

What I'd do next

The model currently processes each mixture independently. The obvious extension is speaker tracking across utterances — if you've seen speaker A once, use that information to separate subsequent mixtures faster. There are also architectures (like SepFormer or DPRNN) that work on the time domain directly and would be worth comparing against on the same dataset.

Code is on GitHub if you want to reproduce it — branch bss_03. The README has the full pipeline including dataset generation.
