# Venkatesan Govindarajan: profile page

One-page profile at https://venkatesan7g.github.io, with small pixel-art animations drawn on the page.

- Content lives in `data/*.json`. Run `node build.mjs` to regenerate `index.html`.
- Animations: `assets/js/scenes.js` and `assets/js/sprites.js`. Styling: `assets/css/paper.css`.
- No frameworks, no tracking, no dependencies. Works without JavaScript for all text content.
